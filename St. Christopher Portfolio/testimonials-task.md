# Task: Create a Testimonials Section (26 Marks)
Follow the instructions below. Write both the HTML and CSS code. Each instruction is worth 2 marks.

## HTML Instructions
1. Create a section with the ID 'testimonials'. This section will contain all the testimonials.
2. Inside the section, add a heading named 'Testimonials' using an h2 tag.
3. Below the heading, create a div with the class name 'testimonial-container'. This container will hold all the testimonial cards.
4. Inside the container, create two testimonial cards. Each card should be inside its own div with the class name 'testimonial-card'.
5. In the first testimonial card, add an avatar image from the Images folder. Below the image, add the name 'John' using an h4 tag and a short testimonial using a paragraph tag.
6. In the second testimonial card, add another avatar image from the Images folder. Below the image, add the name 'Mary' using an h4 tag and a short testimonial using a paragraph tag.

## CSS Instructions
7. Add a padding of 100px 80px to the Testimonials section to create space inside the section. Also give the section a light blue background colour.
8. For the testimonial container, use Flexbox to arrange the testimonial cards in one row. Centre the cards on the page and add a gap of 30px between them.
9. Style each testimonial card by giving it a white background colour, a padding of 20px, a border radius of 15px to round the corners, and a box shadow of 0 8px 20px rgba(0,0,0,0.1).
10. Style the avatar images by setting the width to 80px, the height to 80px, giving them a border radius of 50% to make them circular, use object-fit: cover, centre the images and add a bottom margin of 15px.
11. Style the names by changing the text colour to hot pink, centring the text and adding a bottom margin of 10px.
12. Style the testimonial paragraphs by changing the text colour to dark grey (#555), centring the text and setting the line height to 1.6.
13. Add a hover effect to each testimonial card by making the movement smooth with a transition of 0.3 seconds and moving the card 10 pixels upwards when the mouse is placed over it.
